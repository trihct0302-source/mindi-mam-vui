# V1.4 Visual QA & Clipping Acceptance

## Scope
- Targets: desktop and mobile.
- Priority: image rendering, character bounds, popup clipping, accessory layering, responsive layout.
- Test-only branch and package. Do not merge into production until manual browser sign-off.

## Required viewport matrix
| Viewport | Purpose |
|---|---|
| 1440 × 900 | Desktop baseline |
| 1024 × 768 | Compact desktop |
| 768 × 1024 | Tablet / narrow layout transition |
| 390 × 844 | Standard mobile |
| 360 × 800 | Small mobile |
| 320 × 700 | Minimum-width stress test |

## Popup V2 acceptance
- [ ] Modal frame and all children render without clipping.
- [ ] 9-slice frame does not cover title, portrait, accessory, or action buttons.
- [ ] Equipped accessory is visibly distinct from the currently selected item.
- [ ] Equipped accessory retains its intended 40–48px preview size.
- [ ] Speech bubble wraps naturally and does not force the character outside the modal.
- [ ] Four-column item grid remains readable at 390px; three columns at 360px and below.
- [ ] Long content can be reached without being cut off.
- [ ] Close button and Escape dismiss the preview and restore focus to the tab that opened it.

## Motion V3 acceptance
- [ ] Character sprite is fully visible at all 12 signs × 4 levels.
- [ ] Pet image uses contain sizing and does not crop transparent bounds.
- [ ] Chest, reward, evolution, outfit and gesture effects remain inside the stage.
- [ ] Desktop drag/drop and mobile tap/swipe have visible feedback.
- [ ] Reduced-motion preference suppresses nonessential motion without hiding the final state.

## Asset acceptance
- [ ] 48 character PNGs exist (12 × 4), use alpha transparency and have no opaque edge pixels.
- [ ] 240 animation GIFs exist (12 × 4 × 5 states).
- [ ] No missing local image references.
- [ ] No white matte / white fringe is visible on both light and dark test backgrounds.

## Test evidence
Record browser, OS, viewport, character/level, module, action, expected result, actual result, screenshot link, severity, and pass/fail.

## Known limitation
Automated checks can verify file integrity, dimensions, alpha edges, paths, and CSS rules. They cannot certify visual appearance in Safari/Chrome or actual device rendering. Manual screenshots at the listed viewports remain required.

## Release gate
No production merge, Supabase writes, or production gameplay changes as part of V1.4 QA.
